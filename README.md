# marcozwyssig/tap

Homebrew formulae for the products delivered by [simplon](https://github.com/marcozwyssig/simplon).

```
brew install marcozwyssig/tap/simplon
```

Or tap once and install by name:

```
brew tap marcozwyssig/tap
brew install simplon
```

The formulae are generated, not written by hand: the version, the download URL, its sha256 and the Python
resources come from the released artefact (si#449). A change made here by hand is overwritten by the next
release; change it in the product's manifest or in the kernel instead.
